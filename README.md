# GdprConsent

Filament plugin for laravel-gdpr-consent: the GDPR consent ledger in your panel, read-only, with purpose, decision, terms version, expiry and the proof of each consent (Art. 7).

## Installation

You can install the package via composer:

```bash
composer require jeffersongoncalves/filament-gdpr-consent
```
